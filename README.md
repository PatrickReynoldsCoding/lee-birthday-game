# Lee's Birthday Quest

A tiny GBA-style (240x160) cat-catching game for Lee's 35th birthday. It's all one file: `index.html`.

- **Play locally:** open `index.html` in a browser.
- **Controls:** on a phone, use the on-screen D-pad and A/B buttons in portrait or landscape. On a computer, use the arrow keys, with Z/Enter for A and X for B. M mutes the sound.
- **Change looks:** edit the `LOOK` block at the top of the script to change hair, skin and clothes colours for Lee and Paddy.
- **Deploy:** any static host works (GitHub Pages, Netlify Drop, Cloudflare Pages). Upload `index.html` and `manifest.webmanifest`.
